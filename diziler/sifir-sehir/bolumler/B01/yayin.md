```

```

## Paylaşırken
1. Reels olarak yükle: `B01_kurgu_v2.mp4`.
2. Kapak: "Kapağı düzenle" → galeriden `B01_kapak.jpg` seç. Ardından profil ızgarası kırpmasını ortala.
3. Açıklamayı yapıştır.
4. Gelişmiş ayarlarda yapay zekâ etiketini aç ("AI ile üretildi" / "Yapay zekâ etiketi ekle").
5. Paylaştıktan sonra ilk yorumu yaz ve sabitle.
6. Bölümü profile sabitle (dizinin ilk bölümü olarak).

`B01_kapak_izgara_4x5.jpg` yüklenmez; yalnızca kapağın ızgarada nasıl görüneceğini gösteren önizlemedir.
