# B02 — yayın paketi

**Dosyalar:** Buffer için `cikti/B02_kurgu_v1_kapakli.mp4` (kapak ilk karede, tek kare) · elle yükleme için `cikti/B02_kurgu_v1.mp4` (`python3 araclar/b02_kurgu.py`) · kapak `cikti/B02_kapak.jpg`

## Açıklama metni (önerilen)

```
Borç belli oldu: 333.333 lira. 33 de kuruşu var.
Şalter muhtarda. Muhtar da… 🐐

SIFIR ŞEHİR | Bölüm 2

Sizce Rıza muhtarı ikna edebilir mi? 👇
Devamı için takip et.

#sıfırşehir #yapayzekadizi #minidizi #komedi #dizi
```

## Açıklama metni (alternatif, daha kısa)

```
"Muhtarla hemen bir toplantı ayarlayalım" dedi. Muhtar keçi çıktı. 🐐

SIFIR ŞEHİR | Bölüm 2
Devamı için takip et.

#sıfırşehir #yapayzekadizi #minidizi #komedi
```

## Sabitlenecek ilk yorum

```
Borç: 333.333,33 TL. En yakın tahmin: @… 👏 Sıradaki soru: keçi şalteri verir mi?
```
`@…` yerine B01 yorumlarında 333 bine en yakın tahmini yazan kişiyi yaz. Kimse tahmin yazmadıysa ortadaki cümleyi sil.

## Paylaşırken
1. Reels olarak yükle: `B02_kurgu_v1.mp4`.
2. Kapak: "Kapağı düzenle" → galeriden `B02_kapak.jpg`.
3. Açıklamayı yapıştır, yorumu sabitle.
4. Yapay zekâ etiketini aç.
5. B01'in sabit yorumuna yanıt yaz: "Cevap Bölüm 2'de 👆".
